# 스튜디오 조명 시뮬레이터

영상·사진 촬영용 조명 배치를 3D로 구상해 보는 웹 도구입니다. 브라우저에서 바로 실행되며 설치·로그인이 필요 없습니다.

- 사용: https://jaejae0291-blip.github.io/studio-light-sim/
- 이 저장소에는 **빌드된 사이트 파일만** 들어 있습니다(소스 코드는 포함하지 않습니다).
- 실제 조명 기구·모디파이어의 물리적 정확성을 보장하지 않는 근사 시뮬레이터입니다. 앱 안의 "조명 모델의 한계"를 참고하세요.
- 제품명·상표는 각 소유자의 것이며 이 프로젝트는 제조사와 제휴·보증 관계가 없습니다.
