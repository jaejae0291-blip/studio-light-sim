# rocketbox_female_03.glb

Microsoft Rocketbox Avatar Library 의 `Female_Adult_03`(MIT License)을 GLB로 변환한 파일입니다.
- 출처: https://github.com/microsoft/Microsoft-Rocketbox (Assets/Avatars/Adults/Female_Adult_03)
- 라이선스: 같은 폴더의 LICENSE-Rocketbox.md (Copyright (c) 2020 Microsoft)
- 변환: FBX → GLB(FBX2glTF), 텍스처 TGA → JPEG/PNG(2048px), 재질(PBR) 값은 직접 지정. 스페큘러 맵은 사용하지 않음.
- 특정 국적·민족을 대표하는 모델이 아니며, 외형이 동아시아 인물에 가까운 라이브러리 아바타일 뿐입니다.
